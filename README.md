# PlaceLauncher

<img src="build/avatar.png" width="120" alt="PlaceLauncher" />

Лаунчер Minecraft для Windows: моды, модпаки, бэкапы сборок, разбор крашей, прокси и своё зелёное оформление.

## Возможности

### Аккаунты и запуск
- **Microsoft** — вход через браузер или код устройства, без ручного ввода Client ID (при желании можно указать свой).
- **ely.by** — вход по логину и паролю, можно указать свой сервер авторизации.
- **Оффлайн-режим** — игра без покупки Minecraft.
- Автоматическая загрузка и установка Java (или свой путь к уже установленной Java).
- Все версии Minecraft: релизы и снапшоты (снапшоты включаются переключателем в настройках).
- **Первоапрельский режим** — показывает только шуточные снапшоты Mojang (15w14a, 20w14infinite, 24w14potato, 26w14a и другие).
- Загрузчики модов: **Fabric, Forge, NeoForge, Quilt**.
- Настройка выделяемой памяти и версии Java для каждого экземпляра.

### Экземпляры и моды
- Создание, редактирование и **дублирование** экземпляров; поиск по сборкам.
- Своя обложка: картинка, цвет градиента или автоматический цвет по имени.
- У каждого экземпляра своя папка; кнопка «Папка» открывает её в проводнике.
- Своя папка игры: по умолчанию внутри лаунчера, путь можно поменять в настройках.
- Каталог модов **Modrinth и CurseForge** с поиском и бесконечной подгрузкой.
- Редактор экземпляра с вкладками **Моды / Ресурспаки / Шейдеры / Миры / Скриншоты / Бэкапы / Настройки**.
- Установка и удаление модов, ресурспаков и шейдеров в один клик.
- При создании экземпляра выбранные моды скачиваются автоматически: лаунчер подбирает последнюю стабильную версию под выбранные Minecraft и загрузчик.
- Если нужна другая версия мода, её можно выбрать вручную в редакторе уже созданного экземпляра.
- CurseForge подключается своим API-ключом (ключ хранится только локально).

### Бэкапы сборок
- Перед каждой установкой или удалением мода лаунчер **сам сохраняет снапшот** папок mods, config, ресурспаков и шейдеров.
- Вкладка «Бэкапы» в редакторе сборки: список снапшотов, кнопки **«Вернуть»** и **«Сделать сейчас»**.
- Сломал сборку модом — верни всё как было одним нажатием, без лазания по папкам.
- Хранятся 10 последних бэкапов; миры в бэкап не входят.

### Разбор крашей и «Пофиксить»
- Если сборка упала — лаунчер **читает лог и crash-report** и говорит по-русски, что случилось: мод не для этой версии, дубликат мода, не хватает памяти, не та Java, конфликт миксинов.
- Кнопка **«Пофиксить»**: отключает виновные моды (в папку disabled-mods, без удаления), докачивает недостающий мод-зависимость из Modrinth, поднимает память, скачивает нужную Java или откатывает бэкап.
- После фикса — «Запустить снова» одной кнопкой.

### Модпаки
- Каталог готовых сборок Modrinth и CurseForge с бесконечной подгрузкой.
- Установка модпака в один клик.

### Импорт из Prism Launcher
- Перенос экземпляров из Prism Launcher, включая CurseForge-сборки: моды автоматически докачиваются.

### Прокси
- Автоматический режим: лаунчер сам подбирает рабочий прокси из пула.
- Ручной режим: SOCKS5 / HTTP с хостом, портом и логином/паролем.

### Оформление и интерфейс
- Единая зелёная тема со своим стилем тумблеров, списков и скроллбара.
- Своя ава PlaceLauncher: логотип в сайдбаре, иконка приложения и имя в панели задач.
- Сворачиваемый сайдбар и маскот Кубик в углу окна.
- **Тур-обучение при первом входе**: экран подсвечивает кнопки, Кубик ходит по лаунчеру и рассказывает, что есть что. Повторить можно кнопкой «Пройти обучение заново» в настройках.
- Голова скина аккаунта в меню аккаунтов.
- Экран «Логи» со всеми логами лаунчера и игры и выгрузкой на mclo.gs.
- Кнопка «Удалить лаунчер» в настройках — приложение удалит само себя (сборки и аккаунты останутся).

### Обновления
- Автообновление через GitHub Releases: лаунчер сам проверяет новую версию и докачивает только изменившиеся части.

## Установщики

Собираются командой `npm run package`. Оба ставят одно и то же приложение, разница только в способе доставки:

| Файл | Что делает |
|---|---|
| `placelauncher-0.3.1-setup.exe` (~81 МБ) | **Полный установщик.** Всё приложение внутри одного файла: запустил — установилось, интернет не нужен. |
| `placelauncher-0.3.1-web-setup.exe` (~1 МБ) | **Web-установщик.** Маленький загрузчик: скачивает основной архив (~81 МБ) с GitHub Releases (или берёт файл `.7z`, если он лежит рядом) и устанавливает. Или если нету скачивает из интернета. |

- При установке можно выбрать папку установки.
- После установки лаунчер работает без интернета (оффлайн-режим). Сеть нужна только для онлайн-функций: вход Microsoft, скачивание модов и модпаков и обновления.
