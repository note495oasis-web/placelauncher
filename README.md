# PlaceLauncher

<img src="build/avatar.png" width="120" alt="PlaceLauncher" />

Лаунчер Minecraft для Windows: моды, модпаки, друзья, прокси и своё оформление.

## Возможности

### Аккаунты и запуск
- **Microsoft** — вход через браузер или код устройства, без ручного ввода Client ID (при желании можно указать свой).
- **ely.by** — вход по логину и паролю, можно указать свой сервер авторизации.
- **Оффлайн-режим** — игра без покупки Minecraft.
- Автоматическая загрузка и установка Java (или свой путь к уже установленной Java).
- Все версии Minecraft: релизы и снапшоты (снапшоты включаются переключателем в настройках).
- Загрузчики модов: **Fabric, Forge, NeoForge, Quilt**.
- Настройка выделяемой памяти и версии Java.

### Экземпляры и моды
- Создание и редактирование экземпляров.
- У каждого экземпляра своя папка; кнопка «Папка» открывает её в проводнике.
- Своя папка игры: по умолчанию внутри лаунчера, путь можно поменять в настройках.
- Каталог модов **Modrinth и CurseForge** с поиском и бесконечной подгрузкой.
- Редактор экземпляра с вкладками **Моды / Ресурспаки / Шейдеры** — список обновляется сразу при переключении вкладки.
- Установка и удаление модов, ресурспаков и шейдеров в один клик.
- CurseForge подключается своим API-ключом (ключ хранится только локально).

### Модпаки
- Каталог готовых сборок Modrinth и CurseForge с бесконечной подгрузкой.
- Установка модпака в один клик.

### Импорт из Prism Launcher
- Перенос экземпляров из Prism Launcher, включая CurseForge-сборки: моды автоматически докачиваются.

### Друзья
- Список друзей и их статус: онлайн / в игре.
- Игра по локальной сети через интернет — туннель без настройки сети и проброса портов.
- Обмен модпаками с друзьями.
- Адрес сервера друзей можно указать свой.

### Прокси
- Автоматический режим: лаунчер сам подбирает рабочий прокси из пула.
- Ручной режим: SOCKS5 / HTTP с хостом, портом и логином/паролем.

### Оформление и интерфейс
- Темы: стандартная (белый → чёрный градиент), фиолетово-чёрная и своя палитра (начальный/конечный цвет и угол градиента).
- Сворачиваемый сайдбар.
- Голова скина аккаунта в меню аккаунтов.
- Экран «Логи» со всеми логами лаунчера и игры.
- Кастомные элементы интерфейса и стильный скроллбар в стиле лаунчера.

### Обновления
- Автообновление через GitHub Releases: лаунчер сам проверяет новую версию и докачивает только изменившиеся части.

## Установщики

Собираются командой `npm run package`. Оба ставят одно и то же приложение, разница только в способе доставки:

| Файл | Что делает |
|---|---|
| `placelauncher-0.1.0-setup.exe` (~76 МБ) | **Полный установщик.** Всё приложение внутри одного файла: запустил — установилось, интернет не нужен. |
| `placelauncher-0.1.0-web-setup.exe` (~1 МБ) | **Web-установщик.** Маленький загрузчик: скачивает основной архив (~76 МБ) с GitHub Releases (или берёт файл `.7z`, если он лежит рядом) и устанавливает. Или если нету скачивает из интернета. |

- При установке можно выбрать папку установки.
- После установки лаунчер работает без интернета (оффлайн-режим). Сеть нужна только для онлайн-функций: вход Microsoft, скачивание модов и модпаков, друзья и обновления.
